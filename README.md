# Personal-Portfolio
Full Stack Personal Portfolio Website built using PHP, MySQL, HTML, CSS, and JavaScript with dynamic content management and contact form integration.

## Overview
A full-stack personal portfolio website developed using PHP, MySQL, HTML, CSS, and JavaScript.

## Features
- Dynamic profile information
- Education section
- Skills section
- Projects showcase
- Certifications
- Experience section
- Resume download
- Contact form with database storage
- Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- XAMPP

## Database
The project uses MySQL database named `portfolio_db`.

Import `portfolio_db.sql` into phpMyAdmin before running the project.

## Setup Instructions

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy project folder into `htdocs`.
4. Import `portfolio_db.sql`.
5. Update database credentials in `db.php`.
6. Open:

http://localhost/Personal-Portfolio/
